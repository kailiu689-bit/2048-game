# 2048 小游戏

一个单文件 2048 网页小游戏，浏览器直接打开即可游玩，手机端支持滑动和屏幕方向按钮，无需安装任何软件。

## 在线玩

GitHub Pages 地址：<https://kailiu689-bit.github.io/2048-game/>

## 玩法

- 电脑：方向键 / WASD 移动，Z 撤销，R 重开一局
- 手机：在棋盘上滑动屏幕，或使用屏幕下方的方向按钮（▲◀▼▶）
- 微信里建议用屏幕方向按钮操作，避免滑动被微信当成"返回"手势
- 相同数字的方块碰撞会合并成两倍，分数随之累加
- 连击：一次移动同时合成 2 对及以上方块，会获得连击加分（x2 +10，x3 +20，x4 +30）
- 撤销：每局 3 次机会，可退回上一步；游戏结束后也能用撤销续命
- 宝箱：每走 6 步出现一个宝箱，点击开启直接获得奖励——普通（+100/+200 分）、稀有（+300 分 / 撤销 +1 / 清除 2 个最小方块）、传说（随机方块翻倍 / 撤销 +1 且 +200 分 / 清除 4 个方块且 +100 分）；每局最多 10 个，清除和翻倍奖励可撤销
- 成就：首次达到 128/256/512/1024 会有庆祝提示，合成 2048 获胜
- 音效：右上角 🔊 按钮可随时开关音效和震动
- 进度自动保存：退出后重新打开会接着上次的棋盘继续玩；点「新游戏」重新开始
- 合成 2048 即胜利；16 格全部填满且无法合并时，游戏结束
