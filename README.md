# 2048 小游戏

一个单文件 2048 网页小游戏，浏览器直接打开即可游玩，手机端支持滑动操作，无需安装任何软件。

## 在线玩

GitHub Pages 地址：<https://kailiu689-bit.github.io/2048-game/>

## 玩法

- 电脑：方向键 / WASD 移动，Z 撤销，R 重开一局
- 手机：在棋盘上滑动屏幕即可移动
- 相同数字的方块碰撞会合并成两倍，分数随之累加
- 撤销：每局 3 次机会，可退回上一步；游戏结束后也能用撤销续命
- 宝箱：每走 6 步出现一个宝箱，点击开启随机获得 +100/+200/+300 分或额外 1 次撤销；每局最多 10 个
- 合成 2048 即胜利；16 格全部填满且无法合并时，游戏结束
